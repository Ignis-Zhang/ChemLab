# 实验 2 - 指令系统（概述）

## 实验目的

理解 RISC-V 指令集的关键指令格式与编码方式。

## RISC-V 指令格式

| 格式 | 用途           | 示例                |
|------|----------------|---------------------|
| R    | 寄存器-寄存器运算 | `add rd, rs1, rs2` |
| I    | 立即数运算     | `addi rd, rs1, imm` |
| S    | 存储           | `sw rs2, imm(rs1)`  |
| B    | 分支           | `beq rs1, rs2, off` |
| U    | 高位立即数     | `lui rd, imm20`     |
| J    | 跳转           | `jal rd, off`       |

## 指令编码

以一个简单的 R 型指令为例：

```text
add.w rd, rj, rk
```

编码字段如下：

| bits  | 31-25 | 24-20 | 19-15 | 14-10 | 9-7 | 6-0 |
|-------|-------|-------|-------|-------|-----|-----|
| field | funct7| rs2   | rs1   | funct3| rd  | opcode |
