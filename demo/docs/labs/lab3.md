# 实验 3 - 流水线

## 实验目的

实现一个五级流水线处理器，并处理数据冒险。

## 流水线阶段

| 阶段 | 缩写 | 功能               |
|------|------|--------------------|
| 取指 | IF   | 从指令存储器取指令 |
| 译码 | ID   | 指令译码、读寄存器 |
| 执行 | EX   | ALU 运算           |
| 访存 | MEM  | 数据存储器访问     |
| 写回 | WB   | 写回寄存器堆       |
