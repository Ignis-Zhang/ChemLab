# 关于本站

这是一个用于演示 **Material for MkDocs** 界面架构的 Demo 站点。

本 Demo 复刻了 USTC SOC 课程站的三段式布局：

1. **顶部导航栏** — 站点标题与搜索框
2. **左侧边栏** — 多级可折叠导航树
3. **右侧目录** — 页面内锚点导航

## 技术栈

- [MkDocs](https://www.mkdocs.org/) — 静态站点生成器
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — 主题
- GitHub Pages / 任意静态托管
